Master Custom Library for AutoCAD drawings.

This is a VB.Net collection of various commands, methods, and functions that are useful to AutoCAD drafters.  Most of the commands and functions
were copied from other solutions so they might some editing to be completely useful.  No external libraries are necessary but some require
xml data files or other external data files.  The xsd schema files are embedded in the library and are extracted to the temp folder as needed.

Error checking is not comprehensive.
